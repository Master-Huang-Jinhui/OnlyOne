# 图片存放说明

把你的图片文件放到这个文件夹里，然后在后台填写图片 URL 时使用 `/images/文件名.后缀` 的格式。

## 示例

1. 把图片 `milk-tea.jpg` 复制到这个文件夹
2. 后台 → 内容管理 → 自定义板块 → 编辑
3. 图片 URL 填写：`/images/milk-tea.jpg`
4. 保存后重新构建前端：`npm run build`
5. 刷新前台页面即可看到图片

## 支持的格式
- JPG / JPEG
- PNG
- GIF
- WebP
- SVG

## 注意事项
- 文件名不要用中文，建议用英文或拼音
- 文件名不要有空格，用连字符 `-` 或下划线 `_` 代替
- 图片建议压缩到 500KB 以内，加载更快
- 每次添加新图片后都需要重新 `npm run build`
