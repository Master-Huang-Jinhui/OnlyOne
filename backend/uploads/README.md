# 外卖报表 CSV 文件存放目录

这个文件夹用来存放从 Uber Eats、DoorDash、Grubhub 等外卖平台后台下载的月度报表 CSV 文件。

## 文件结构

```
backend/uploads/
├── reports/          # 外卖平台报表 CSV
│   ├── report-1727100000-a1b2c3.csv
│   ├── report-1727200000-d4e5f6.csv
│   └── ...
└── images/           # 商品/平台 Logo 等图片
```

## 怎么用

1. 去各个外卖平台商家后台，下载月度报表 CSV
2. 后台 → 外卖管理 → 外卖报表 → 上传 CSV
3. 系统自动解析并保存到这个文件夹

## 注意

- 不要手动删除这个文件夹里的文件，删除报表请在后台操作（会自动删文件）
- 备份数据时记得连这个文件夹一起备份
