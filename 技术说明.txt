========================================
  Only One 一站式管理系统 - 技术说明
========================================

【项目概述】
Only One BBQ & Tea 一站式管理系统，整合外卖平台跳转管理 + 完整点餐系统（前台顾客端 + 后台管理端）。
支持 Mac / Windows 双击运行，局域网访问，数据本地存储。

【技术栈】

一、后端技术
1. Node.js - JavaScript 运行时环境，跨平台，Mac / Windows / Linux 均可运行
2. Express.js - 轻量级 Web 应用框架，处理 HTTP 请求、API 路由、静态文件服务
3. SQLite + better-sqlite3 - 嵌入式关系型数据库，数据存储为单个 .db 文件，无需安装数据库服务
4. jsonwebtoken (JWT) - 用户登录认证，生成 Token，无状态认证
5. bcryptjs - 密码加密哈希，用户密码不以明文存储
6. cors - 跨域资源共享

二、前端技术
1. React 18 - 用户界面构建库，组件化开发
2. Vite - 前端构建工具，开发服务器启动快，生产构建产物体积小
3. React Router - 前端路由管理，支持前台 / 后台多页面切换
4. Tailwind CSS - 原子化 CSS 框架，浅蓝色 + 白色主题
5. 自研 shadcn/ui 风格组件库 - 不引入重型 UI 库，自行实现常用组件，体积小

三、数据库表结构（13张表）
1. users - 用户表
2. platforms - 外卖平台表
3. categories - 商品分类表
4. products - 商品表
5. orders - 订单表
6. settings - 系统设置表（键值对存储）
7. menus - 后台菜单表
8. forms - 自定义表单表
9. form_submissions - 表单提交记录表
10. content_blocks - 内容区块表
11. carousel - 轮播图表
12. memos - 备忘录/重点事项表
13. role_permissions - 角色权限表

【运行原理】
1. 前端通过 Vite 构建为静态 HTML/CSS/JS 文件（frontend/dist）
2. 后端 Express 同时提供 API 接口和前端静态文件
3. 双击启动脚本自动检查 Node.js、安装依赖、构建前端、启动服务、打开浏览器
4. 服务监听 0.0.0.0:3000，支持本机和局域网访问
5. 数据存储在 backend/data.db，整个文件夹复制即可迁移

【默认账号】
- 管理员账号：admin
- 管理员密码：admin

【系统要求】
- 操作系统：Windows 10/11 或 macOS 10.15+
- 运行环境：Node.js 16 或更高版本（LTS 推荐）
- 内存：最低 2GB，推荐 4GB 以上

【局域网访问说明】
1. 确保电脑和其他设备连接同一个 WiFi
2. 启动服务后，控制台会显示局域网地址
3. 其他设备在浏览器输入该地址即可访问
4. Windows 首次启动可能弹出防火墙提示，请允许
5. 电脑主机必须保持开机，服务必须在运行

【数据迁移说明】
1. 整个 OnlyOne 文件夹复制到 U 盘 / 云盘 / 另一台电脑
2. 在新电脑上安装 Node.js
3. 双击启动脚本即可运行
4. 所有数据都在 backend/data.db 中
5. 多台电脑的数据独立，不会自动同步，需要手动复制文件夹覆盖
