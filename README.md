# Only One 一站式管理系统

Only One BBQ & Tea 外卖平台管理 + 点餐系统（前台顾客端 + 后台管理端），基于 Node.js + SQLite + React，支持 Mac/Win 双击运行、局域网访问。

## 功能特性

### 前台顾客端（无需登录）
- 首页：轮播图、品牌故事、茶品溯源、奶茶工艺、商品菜单、联系我们
- 商品菜单：分类筛选、商品展示、一键加购
- 购物车：数量调整、备注编辑（仅购物车内）、自动合并
- 结算：堂吃/自取/配送三选一、税率自动计算（默认8.8875%）、配送费规则、营业状态校验
- 响应式设计，适配手机/平板/电脑
- 滚动动画、悬浮侧边导航、淡入上移效果

### 后台管理端（需登录）
- 仪表盘：订单统计、营收统计、外卖平台概览、备忘录/重点事项
- 外卖平台管理：Logo、名称、跳转URL、账号密码、电话、备注、启用状态
- 商品管理：商品增删改查、分类管理、推荐标记、上下架
- 订单管理：订单列表、状态筛选、订单详情、状态流转
- 用户管理：用户增删改查、角色分配（admin/普通用户）、启用禁用
- 权限管理：基于角色的菜单可见性控制
- 菜单管理：一级二级菜单动态配置、图标、路径、排序
- 表单管理：自定义表单构建器，支持文本/数字/下拉/单选/多选/日期/时间/开关等12种字段
- 内容管理：轮播图、品牌故事、茶品溯源、奶茶工艺、关于区块，中英双语
- 系统设置：店铺信息、营业时间（7天独立配置，周二默认休息）、税率、配送规则、堂吃二维码生成

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端 | Node.js + Express | 轻量 Web 服务 |
| 数据库 | SQLite + better-sqlite3 | 单文件数据库，复制即用 |
| 前端 | React 18 + Vite | 组件化开发，快速构建 |
| 样式 | Tailwind CSS | 原子化 CSS，浅蓝色主题 |
| UI 组件 | 自研 shadcn 风格 | 轻量组件库 |
| 认证 | JWT + bcryptjs | 无状态登录，密码加密 |

## 快速开始

### 环境要求
- Node.js 16+（推荐 LTS 版本）
- Windows 10/11 或 macOS 10.15+

### 运行方式

#### Windows
双击 `启动.bat`

#### Mac
在终端中执行：
```bash
chmod +x 启动.command
./启动.command
```

首次运行会自动安装依赖并构建前端，需要几分钟。启动后自动打开浏览器访问 http://localhost:3000

### 默认账号
- 账号：`admin`
- 密码：`admin`

## 局域网访问

1. 确保所有设备连接同一个 WiFi
2. 启动服务后，控制台会显示局域网地址
3. 其他设备浏览器输入该地址即可访问
4. 堂吃二维码：后台 → 系统设置 → 堂吃二维码，生成后打印贴餐桌

## 数据迁移

整个 `OnlyOne` 文件夹复制到 U 盘 / 云盘 / 另一台电脑，双击启动脚本即可运行。所有数据都在 `backend/data.db` 中。
